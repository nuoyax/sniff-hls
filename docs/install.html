Sniffls 安装指南

一键构建 · 分浏览器加载 · Chrome / Edge / Firefox / Safari
Manifest V3 WXT + React + TS v0.1.5

前置准备

所有浏览器都从同一份源码构建，先装好依赖。

⬇
Node.js 20+  ·  在项目根目录执行一次：
$ npm install

选择你的浏览器

点击下方对应标签查看构建与加载步骤。

构建命令npm run build
产物目录.output/chrome-mv3/
最低版本Chrome 109+
# 构建 Chrome / Edge（同一份 Chromium 产物） $ npm run build # → .output\chrome-mv3\
  1. 打开 chrome://extensions
  2. 开启右上角的 开发者模式（Developer mode）
  3. 点击 加载已解压的扩展程序（Load unpacked）
  4. 选择文件夹 .output/chrome-mv3/
  5. 工具栏出现 Sniffls 图标，建议固定（pin）方便使用
提示：Chrome 与 Edge 共用同一份 Chromium 产物，Edge 加载时选同一个 chrome-mv3 文件夹即可。
构建命令npm run build
产物目录.output/chrome-mv3/
最低版本Edge 109+
# Edge 复用 Chromium 构建 $ npm run build # → .output\chrome-mv3\
  1. 打开 edge://extensions
  2. 开启左侧边栏的 开发人员模式（Developer mode）
  3. 点击 加载解压缩的扩展（Load unpacked）
  4. 选择文件夹 .output/chrome-mv3/
  5. 在工具栏固定 Sniffls 图标
分发：如需打包成 .zip 供内部分发，运行 npm run zip，产物在 .output/sniff-hls-0.1.5-chrome.zip。
构建命令npm run build:firefox
产物目录.output/firefox-mv3/
最低版本Firefox 115+
# 构建 Firefox $ npm run build:firefox # → .output\firefox-mv3\
方式一 · 临时加载（最快） — 重启 Firefox 后失效
  1. 地址栏打开 about:debugging#/runtime/this-firefox
  2. 点击 临时加载附加组件…（Load Temporary Add-on…）
  3. 选择文件 .output/firefox-mv3/manifest.json（选 manifest，不是文件夹）
  4. 扩展立即加载，工具栏出现 Sniffls 图标
方式二 · 永久安装 — 需 Developer / ESR / Nightly 版或上架 AMO
# 打包成 zip / xpi $ npm run zip:firefox # → .output\sniff-hls-0.1.5-firefox.zip # 改后缀即 .xpi：cp sniff-hls-0.1.5-firefox.zip sniff-hls-0.1.5-firefox.xpi
  1. 在 about:config 中设置 xpinstall.signatures.required = false（仅 Developer/ESR/Nightly 可改）
  2. 把 .xpi 文件拖进 Firefox 窗口
  3. 确认安装
正式版 Firefox：必须先在 addons.mozilla.org 上传 .zip 完成签名，通过审核后从商店安装。
构建命令npm run build:safari
产物目录.output/safari-mv3/
最低版本Safari 16+ / macOS
需要 Xcode。Safari App Extension 必须打包进一个 Xcode 工程后才能安装，WXT 只产出源码。
$ npm run build:safari # → .output\safari-mv3\
  1. 打开 Xcode，新建一个 Safari Web Extension target，包裹 .output/safari-mv3/
  2. Build & Run，在模拟器或本机 Safari 中安装
  3. 在 Safari → 设置 → 扩展 中勾选启用
  4. 在 开发 → [你的扩展] 中允许运行
Safari 限制：不支持代理 API；下载引擎与其它浏览器共用同一隐藏页面 download-runner。
